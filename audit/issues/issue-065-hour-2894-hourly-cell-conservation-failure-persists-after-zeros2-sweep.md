### Step 5: reading `erosion_chemistry_bridge.zig` -- the exact mechanism

```zig
inline for (@typeInfo(geochemistry.SolidState).@"struct".fields) |field| {
    try put(@field(chemistry.geochemistry_solids[layer], field.name) * water + @field(chemistry.pending_geochemistry_solids_mol[layer], field.name), output, &cursor);

```
where `water = water_m3[layer]` is the raw carrier. At hour 2,894, `water = 0` exactly (live water has already collapsed post-WATSUB-commit; this is the identical transition the third/fourth addenda characterized in detail). `:226-231` (`unpackMapped`, same loop, using the same raw `water`):
```zig
inline for (@typeInfo(geochemistry.SolidState).@"struct".fields) |field| {
    const next = try ownedConcentration(input[cursor], water);
    @field(chemistry.geochemistry_solids[layer], field.name) = next.concentration;
    @field(chemistry.pending_geochemistry_solids_mol[layer], field.name) = next.pending_mol;
    cursor += 1;
}
```
`ownedConcentration` (`:243-252`): `if (scale > 0) return .{.concentration = amount/scale, .pending_mol = 0}; return .{.concentration = 0, .pending_mol = amount};`. With `water = 0`, `scale = 0`, so this **unconditionally sets `chemistry.geochemistry_solids[layer].field.concentration = 0`**, overwriting the true prior concentration -- the round-trip does not merely fail to preserve it, it actively zeroes it, regardless of what `exchangeLocal`'s routing math did with the (already-zeroed) packed value in between.
