# Feature ID: FEAT-021-STARTQ-PLANT-VARIABLE-INITIALIZATION

Status: PARTIALLY_ASSESSED (source-audit, first dossier for this file; `startq.f` is 919 lines, fully read this pass; Zig-side tracing covers the modules that self-cite `startq.f` by line number, not every sub-array independently re-derived)

## Scope and provenance

Legacy source: `f77src/startq.f` (sha256 `F117240373D88D95D8204AC8241A4F8DD30BA3B6F864E7BFB5581080E0532CCB`). **Identity verified, not assumed from the filename**: header states "THIS SUBROUTINE INITIALIZES ALL PLANT VARIABLES" (`:3`). This refutes the naming-convention hypothesis that motivated this pass (that `starte.f`/`startq.f`/`starts.f` split neatly into soil-chemistry/soil-physical/soil-organic domains): `starte.f` is soil chemistry (`FEAT-008`), but `startq.f` is per-PFT **plant/vegetation** state initialization, and `starts.f` (this pass's sibling dossier, `FEAT-022`) is the broader soil-and-landscape-and-ecosystem initializer. The three files are called in the sequence `starte, startq, starts` per the makefile's `SRCS` ordering, but that ordering is a build-dependency artifact, not a domain partition.

Called once per PFT (`NZ`) within each grid cell (`NY,NX`), nested `DO 9995 NX / DO 9990 NY / DO 9985 NZ` (`:63-66`). Three admission gates control how much of the body executes for a given PFT-cell:
- `IFLGN(NZ,NY,NX).EQ.0` (`:67-72`): fresh-vs-retained planting/harvest dates from the PFT file vs. values already advanced by `routp.f`.
- `IYR0(NZ,NY,NX).EQ.IYRC` (`:73-84`): whether this PFT is (re)planted in the current simulation year, controlling population (`PP`/`PPZ`/`PPX`) initialization.
- `IFLGC(NZ,NY,NX).EQ.0` (`:93,673,731-732`): "not yet alive" -- gates the large body (`:93-732`) that seeds litter-kinetic fractions, phenology, morphology/biomass zeroing, mass-balance accumulators, standing-dead stalk mass, and canopy heat/water state. A living PFT (`IFLGC=1`) skips straight to the always-executed root/mycorrhizal loop (`:734-885`) and the seed-morphology finalization (`:845-885`, itself nested inside the `IFLGC.EQ.0` block, so actually only for newly-admitted PFTs) and the per-PFT numerical thresholds (`:886-888`).

No `>1`/`==1`/`==0`/`<0`/else-style **magnitude**-sentinel ladder (the pattern documented for `starte.f`'s `RC0P` outlier and confirmed to actually live in `starts.f`'s `THW`/`THI` decode, see `FEAT-022` finding 8) was found anywhere in `startq.f`. Its gates are boolean/categorical flags (`IFLGN`, `IFLGC`, `IYR0.EQ.IYRC`), not magnitude-coded sentinels.

Both the unbound reference kernel and the bound production owner (`plant/partition/litter.zig`, not independently re-read line-by-line this pass) trace to `startq.f:113-285`. Disposition: `preserved`, on the strength of the in-repo pinning test rather than an independent re-derivation this pass.

### 6. Mycorrhizal (N=2) defaults copied from root (N=1); nodule-only extra block for N=1 -- `preserved` by inspection, Zig side not independently re-verified this pass
