### 6. Restricted (ISALTG=0) NH4-NH3 band mirror: a genuine legacy stale-variable defect, faithfully and deliberately preserved by Zig -- but the whole restricted-domain soil-chemistry pathway is unwired in production

Compared `solute.f:1461-1494` (full-salt NH4-NH3 dissociation, non-band `RNH4` and band `RNHB`) against its restricted-domain mirror at `:3557-3588`. Two differences found:
1. Restricted-branch `XMINP` drops the `AMIN1(CHY1,...)` wrap present in the full branch, for **both** `RNH4` and `RNHB` symmetrically -- a restricted-vs-full simplification, not a band-vs-non-band asymmetry; same category as the already-accepted quirks in Finding 4.
2. Within the restricted branch itself, non-band `RNH4` (`:3561`) correctly bounds against `-XMINN` (freshly computed at `:3558`), but band `RNHB` (`:3578`) bounds against `-XMIN` instead -- a stale scratch variable last assigned by the *unrelated* potassium cation-exchange substrate limit (`XMIN=FIONC*AMIN1(XKA1,CKA1)`, `:3494`) earlier in the same block. This **is** a genuine band-vs-non-band asymmetry, and a real legacy defect (not a documented design choice): there is no scientific rationale for band-NH4's rate floor to reuse potassium's substrate limit.

Zig already has this exact quirk identified and deliberately, explicitly preserved: `ecosys-ng/src/soil/solute/aqueous_reaction_rates.zig` (sha256 `BC6E1581D8F1CC4EBC012919BF92BAA490CEA9ECCFCE13E5DAF13DD9E8811418`), `calculateRestrictedAmmoniumSourceOrder` (`:82-142`), takes the retained value as an explicit parameter (`retained_band_negative_limit_mol_n_per_m3_step`, `:71`, doc comment: "SOLUTE.F line 3578 uses retained `XMIN`, not the `XMINN` assigned at line 3575. It is explicit here rather than reproducing hidden storage."), with a dedicated test (`:441-472`) verifying the exact retained-vs-fresh-limit behavior. Disposition `preserved` for the formula itself.

However: a whole-codebase grep found **no production caller** of `calculateRestrictedAmmoniumSourceOrder`, nor of phosphate's analogous `calculateRestrictedSourceOrder`/`calculateRestrictedBandSourceOrder` (`ecosys-ng/src/soil/solute/phosphate_exchange.zig`, sha256 `02C87C082842D30211620F9A7FA74ADB46040D80A72F600B7A3A51555DE09504`, `:61-134,139-`). These functions exist only in their own defining files and in-file tests. The per-cell static/dynamic-salt flag is wired through many other subsystems (snow, tillage, root uptake, fire/combustion, fertilizer-band amalgamation, litter's own carboxyl gate) but not through the core soil reaction-chemistry stage, which always uses the full/dynamic formulas for soil layers regardless of the flag. This means `ISALTG=0` soil-layer chemistry -- including the correctly-preserved `:3578` quirk -- is currently dead code from production's perspective. Full write-up: `audit/issues/issue-037-solute-restricted-soil-chemistry-formulas-unwired.md`.

### 9. Surface-charge / anion-exchange-capacity site-protonation derivation -- `preserved`; restricted-domain omission consistent with, and further evidence for, `issue-037`

`XAEC` (anion exchange capacity, mol) itself is a fixed per-cell input read at `starte.f:209` (`XAEC=AEC*BKVLX`, outside `solute.f`'s scope); what `solute.f` derives is the pH-dependent *partitioning* of that fixed total capacity among protonated (`R-OH2+`), neutral (`R-OH`), and deprotonated (`R-O-`) surface-site states -- the actual "surface charge" mechanism. Traced the complete lifecycle: state loading (`:456-520`, `XOH01/XOH11/XOH21=XOH0/XOH1/XOH2 / BKVLPO` non-band, `XH01B/XH11B/XH21B` band, both zeroed under the `VOLWPO`/`VOLWPB` dry-zone gate), the site-protonation equilibria themselves (`:979-990` non-band `RXOH2`/`RXOH1` computing `XOH1Q=SXOH2*XOH21/AHY1` and `XOH0Q=SXOH1*XOH11/AHY1`; `:1106-1117` band `RXO2B`/`RXO1B`, same form), immediately followed in both zones by the H2PO4/HPO4 exchange with those same sites (`:998-1082` non-band, `:1118-1174` band -- already the material cited by Finding 4), and the closure (`:2402-2411`, `XOH01=XOH01+RXH0` etc.). This is the same line range Finding 4 already cited, examined here specifically for the site-charge sub-equations rather than the phosphate-exchange sub-equations layered on top of them.

Zig: `ecosys-ng/src/soil/solute/phosphate_exchange.zig` (sha256 `02C87C082842D30211620F9A7FA74ADB46040D80A72F600B7A3A51555DE09504`), `calculateForZone` (`:260-360`, doc comment at `:268` explicitly citing "SOLUTE.F 54-55, 981-1032: site protonation gives XOH2/XOH = H/Ks") computes `protonated_to_hydroxyl_site_mol_per_megagram` (= `RXOH2`/`RXO2B`) and `hydroxyl_to_deprotonated_site_mol_per_megagram` (= `RXOH1`/`RXO1B`) in the same function that derives the H2PO4/HPO4 exchange fluxes, confirming the two are correctly modeled as one coupled mechanism on both sides. Confirmed production-wired via `chemistry_state.zig:1574` (`phosphate_exchange.calculate(...)` for the non-band zone).

Checked the restricted-domain (`ISALTG=0`) mirrors (`:3050-3139` non-band, `:3243-3339` band) specifically for this sub-mechanism: **the site-protonation reactions (`RXOH2`/`RXOH1`/`RXO2B`/`RXO1B`) are entirely absent** -- the restricted branch goes straight from the section header to the H2PO4/HPO4 exchange reactions, treating `XOH0/XOH1/XOH2` as static rather than re-equilibrating them against `AHY1` each substep. This is consistent with, and adds further evidence for, this dossier's own Finding 5 characterization of the restricted branch as a documented subset ("mostly those for phosphorus and co-reactants") and Finding 6/7's already-filed `issue-037` (the entire restricted-domain soil-chemistry pathway has no production caller) -- not filed as a separate issue. Also noted in passing, not filed as an issue for lack of numerical impact: the restricted band block's `RYH2B` (`:3276-3277`) uses `FIONX` where its neighbors `RXH2B`/`RXH1B` use `FIONN`; since `FIONN=FIONZ` (`:141`) and `FIONZ=FIONX=0.20` are identically-valued `PARAMETER` constants (`:119`), this is a harmless copy/paste inconsistency with zero numerical effect, not a genuine defect.
