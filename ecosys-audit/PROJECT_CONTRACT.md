# Scientific contract

Authority and autonomy: `.agent/protocol.md`. One model decides every project question from
evidence; no approval queue. Required scope is complete legacy-to-Zig science traceability
and the full Ottawa release, including dormant branches in the audit inventory.

Protect `f77src/`, `f77example/`, `ecosys-ng-prod-examples/`; stage instrumented copies inside
the repository. Zig 0.17.x; preserve actual legacy f64/integer/layout semantics. Unchanged
kernels require tight justified matched-state checks; approved physical replacements require
separate predeclared scientific envelopes and causal attribution. Exact discrete fields stay
exact. Conservation and trajectory parity are separate obligations.

Preserve fixed external hours, Newton/Anderson, bounded transactional internal solves. Accept
only finite, physically admissible, converged states with independent local/global ledgers.
Never loosen tolerances, raise ceilings to pass, clamp after solve, silently retry science,
forge success, or publish unclosed states. Register intentional changes with mechanism,
source references, measured impact and retirement/equivalence decision.

Use [numerical recovery](../.agent/playbooks/convergence-and-balance.md) for near-zero values,
signed outstanding balances, negative pools and nonlinear stalls. Benign edge cases must
advance promptly without false errors through all scientific gates. Keep process floors,
solver criteria, arithmetic uncertainty and conservation rules distinct; preserve both signed
and absolute cumulative defects. Surplus/deficit bookkeeping never authorizes a physical
source, sink, balancing reserve or rebase. Corrections must close the responsible transfers.
Prevent NaN/Inf and physically invalid finite states at their origin and before commitment,
including ReleaseFast. Reject invalid private probes transactionally within budget; bad input/
committed state or unrecoverable failure must stop with context and nonzero exit. No silent
replacement numbers, warning-only success or next-hour compensation. Check per-interval local
admissibility and explain large transitions with units, supply/energy and forcing. Repair and
attribute analogous legacy vulnerabilities in Zig while retaining invalid oracle evidence.

Scientific accuracy, complete translation/bindings and comparable full Ottawa outputs (F1–F5)
precede runtime optimization. Speed has no acceptance value while any of those fails.

Stages are BASELINE → SOURCE → ENTRY → CAMPAIGN → RELEASE. Cycle gates are G1–G9; never
reuse these names for different stage meanings. Focused tests occur throughout; expensive
qualification follows readiness. Final evidence concerns one integrated candidate.

Use raw-format adapters with complete keys, files, columns, units and time semantics. Reject
truncation/duplicates/nonfinite values. All artifacts/caches remain repo-local. Measured
performance preserves outputs/checks/precision; full Ottawa ReleaseFast must be reproducibly
faster than the optimized precision-preserving legacy run on comparable resources. Git push is required each completed cycle.

[Qualification evidence](qualification-evidence.md) defines executable stage/status compatibility,
acceptance prerequisites and report contracts. Empty registers and unestablished rules block
qualification. Inventory completeness and scientific derivations still require separate review.
