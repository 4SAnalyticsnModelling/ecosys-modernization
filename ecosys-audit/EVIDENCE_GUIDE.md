# Evidence

Authority: `.agent/protocol.md`. Run heavy commands through `scripts/project.sh exec`.
Record argv/cwd, source and dirty digest, exact toolchain/target/options, effective inputs,
executable hash, process start identity, logs, test counts and explicit scope/time coverage.
Hash evidence files; changed dependencies invalidate verdicts. A process exit is not a science pass.

Cycle gates: G1–G9. Release stages: BASELINE, SOURCE, ENTRY, CAMPAIGN, RELEASE. Keep PASS,
FAIL, NA and INCONCLUSIVE distinct; justified NA never waives a relevant scientific gate.
Maps and synthetic tool tests prove bookkeeping behavior, not model correctness.

Matched-state tests compare individual terms/interfaces. Production comparisons align full
calendar/grid/layer/species keys and verify every file/column, units, cumulative resets and
end time. Use separate unchanged-physics and approved-feature rules fixed before acceptance.
Independent ledgers assemble storage/flux terms separately from solver residuals.

For [numerical edge cases](../.agent/playbooks/convergence-and-balance.md), retain signed raw
residual, units/scope, normalization reference, scientific allowance, arithmetic estimate and
derivation, active branch/floors, iteration/evaluation counts and recovery decision. Include
local/global/cumulative balances and admissibility; record benign success and both-sign defect
rejection. A rounded printed zero or a small update proves neither closure nor convergence.
For nonfinite/domain faults, record the first producing operation/operands and detection boundary,
production build/float modes, recovery or fatal exit, and clean state/output/checkpoint proof.
For finite excursions retain adjacent hours, native units/reference, supply/energy/forcing
derivation and local physical bounds. Historical examples are leads until reproduced; later
cancellation and invalid legacy agreement prove no acceptance. Retain source/repair/test coverage
for related hazards, and distinguish document review from implemented runtime enforcement.

Raw logs/runs stay under `audit/runs/` and `evidence/runs/`; commit compact receipts/manifests,
not binary decks/caches. Investigations live under `audit/issues/`. Keep reports short and
pointer-cited. Scientific receipts may be historical; only current hash-bound checks close gates.

Use [qualification evidence](qualification-evidence.md) for versioned report schemas, dependency
manifests, inventory completeness and named suite assessment. Finish schema 2 requires structured
F2–F6 reports; existing certificates and unbound verdicts require revalidation.
