# HYPOTHESIS: T-00060

## Observed defect
In T-00058, while the fixed-pH per-source STARTE M-loop speciation and linear flux mix were structurally verified, SAGE (T-00059) identified four unresolved issues:
(R1) The matched-state oracle lacked legacy gfortran provenance and used wide tolerances (relative 0.15, absolute up to 5e-3) insufficient to detect discrepancies in the explicit Picard sequence.
(R2) Dynamic carbonate seeding for K=1 (rain) was bound to hourly rain gas while K=2 (irrigation) passed zero, producing zero carbonate/bicarbonate ion pairs for irrigation. Legacy `starte.f:234-242` seeds CCO21 for both K=1 and K=2 from atmospheric CO2 (`CCO2EI`) and mean annual air temperature (`ATCA`).
(R3) Speciation was recomputed hourly using live `soil_chemistry.aqueous[topsoil].hydrogen` with a hidden 1.0e-4 fallback on non-positive values, diverging from legacy STARTE which runs per initialization/event using topsoil pH `PH(1)`.
(R4) The primary channel `primary_g_per_m3[10..17]` returned unspeciated input ions. In dynamic salt mode, base cations and anions are carried by `salt_mol`; populating them on `primary_g` risks double counting in `snow_surface_discharge` and `hourly_cell_conservation`.

## Evidence
- `f77src/starte.f:112, 234-242`: `CCO2M = CCO2EI(NY,NX)/12.0`, `CCO21 = CCO2M * SCO2X / EXP(ACO2X) * EXP(0.843 - 0.0281 * ATCA(NY,NX))` for all `K.NE.3` (rain and irrigation), `CCO31 = CCO21 * DPCO3 / CHY1**2`, `CHCO31 = CCO21 * DPCO2 / CHY1`.
- `f77src/starte.f:439`: `AHY1 = 10.0**(-(PH(L,NY,NX)-3.0))` with `L=1` for K=1 and K=2, holding AHY1 constant across the 1000 M-loop iterations.
- `f77src/starte.f:1234-1260, 1285-1315`: exports speciated free ions (`CAL1`, `CFE1`, `CCA1`, `CMG1`, `CNA1`, `CKA1`, `CSO41`, `CCL1`) and complexes for both rain (`*R`) and irrigation (`*Q`).
- `f77src/trnsfrs.f:445-528`: linear flow-weighted superposition `X*BLS = FLQGQ * C*R + FLQGI * C*Q` without re-equilibration.
- `f77src/soil.f:106-109`: STARTE runs once at start or restart, not hourly.
- `ecosys-ng/src/soil/solute/snow_solute_transport.zig:415-424, 495-510`: dynamic cells own base ions in `salt_mol_per_m3` (41 species), while static cells own them in `static_ion_g_per_m3`.
- `ecosys-ng/src/soil/water/snow_surface_discharge.zig:210-252, 253-290`: unconditionally accumulates both `primary_g[10..17]` and `salt_mol[0..9]`, confirming that non-zero values on both channels cause double counting.
- `ecosys-ng/src/validation/hourly_cell_conservation.zig:731-765`: accumulates both `primary_g[10..17]` and `salt_mol[0..9]`.
- `.agent/results/T-00059.md`: SAGE review defining requirements R1-R4.

## Proposed mechanism
1. Speciate dynamic inputs using the legacy STARTE M-loop equations with `CHY1 = 10.0**(-(source_ph - 3.0))` and `AHY1 = 10.0**(-(soil_ph - 3.0))` evaluated at topsoil activity pH `PH(1)` (`topsoil_hydrogen * monovalent_activity_coefficient`).
2. Seed CCO21 for both K=1 and K=2 using the STARTE closed-form equation from atmospheric CO2 (`CCO2EI`) and mean annual air temperature (`ATCA`): `CCO21 = (CCO2EI / 12.0) * (SCO2X / exp(ACO2X)) * exp(0.843 - 0.0281 * ATCA)`.
3. Eliminate the hidden 1.0e-4 fallback: enforce an explicit error (`error.InvalidSoilHydrogenForDynamicInput` / `error.InvalidSoilPhForSpeciation`) if soil hydrogen or pH is non-positive or non-finite.
4. Hoist `DynamicInputSpeciationState` into persistent context state. Invalidate the speciation cache only on STARTE-equivalent triggers: startup, checkpoint restart (`restoring_checkpoint`), or calendar day transition (`IDAYR != IOLD`). Because input chemistry is constant across events/weather files, cached speciation avoids redundant 1000-cycle solves while matching legacy start-time evaluation semantics, ensuring hourly fluctuations in topsoil hydrogen do not re-speciate.
5. In `primary_g_per_m3`, leave indices 10..17 as 0.0 for dynamic inputs (or size to `primary_species_count`), since all speciated base cations and anions are carried by `salt_mol_per_m3`, eliminating double-counting in downstream surface discharge and boundary conservation.
6. Build a standalone gfortran matched-state oracle harness (`ecosys-audit/tests/starte_mloop_oracle.f`) compiled under standard oracle flags (`-ffixed-form -fdefault-real-8 -fdefault-double-8 -std=legacy`). Execute the harness to generate reference outputs for K=1 and K=2 with 17 significant digits. Characterize the 1000-cycle Picard relaxation oscillation over M=980..1000, tighten primary NH4/NH3 checks to 1e-6/5e-4, bound limit-cycle attractor species to empirical spread (Ca <= 0.035 / 0.008, Na <= 0.005 / 0.045, SO4 <= 0.065 / 0.080), and assert that 20-cycle solve values strictly fail the production check.
7. Verify that the rain CO2 primary channel retains the live hourly dissolved gas from `hour1.f:2463-2466` CCOR when supplied.
