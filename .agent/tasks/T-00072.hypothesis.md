# HYPOTHESIS: T-00072

## Observed defect
1. R1: `snow_initialization.zig` used symmetric relative tolerances fitted to the unperturbed M=980..1000 oscillation envelope instead of verifying the first diverging cycle against gfortran P=0 and asserting that M=1000 lies inside the `[min, max]` envelope of the union of gfortran P∈{0,1,2} trajectories over M=980..1000.
2. R3: `triggerDailySpeciation` in `hourly_process_driver.zig` bypassed legacy's PH round-trip (`AHY1 = 10^-(PH-3)` from `PH = -log10(AHY*1e-3)`, `starte.f:439`, `solute.f:854`), directly using `hydrogen * γ1`.
3. R3: In `hourly_process_driver.zig:654-657, 726-729`, live topsoil hydrogen was guarded even when event state was present, causing failure on bad live hydrogen despite valid event AHY1.
4. R3: The unit test for invalid event hydrogen in `hourly_process_driver.zig` tested a local ternary expression without exercising any production helper.

## Evidence
- SAGE review verdict T-00071 (`.agent/results/T-00071.md`).
- Legacy references: `f77src/starte.f:439` (`AHY1=10.0**(-(PH(L,NY,NX)-3.0))`), `f77src/solute.f:854` (`PH(L,NY,NX)=-LOG10(AHY2*1.0E-03)`), `f77src/soil.f:106-109`.
- Source lines: `ecosys-ng/src/stages/hourly_process_driver.zig:220-225, 654-657, 726-729, 1793-1803`; `ecosys-ng/src/soil/chemistry/snow_initialization.zig:2260-2285, 2410-2435`.

## Proposed mechanism
1. Compute per-cycle Zig and gfortran P=0 speciation values for M=20..1000 across all species to identify the first cycle M where relative difference exceeds 1e-12 and trace the responsible operation.
2. In `snow_initialization.zig`, replace the symmetric tolerances with assertions verifying that Zig's M=1000 values lie inside `[min, max]` of the union of gfortran P∈{0,1,2} trajectories over M=980..1000.
3. In `hourly_process_driver.zig` `triggerDailySpeciation`, compute `ph = -log10(ahy_raw * 1e-3)` and `ahy1 = 10^-(ph - 3)`, matching `solute.f:854` and `starte.f:439`.
4. In `hourly_process_driver.zig`, extract production helper `effectiveTopsoilHydrogen` which accesses event state when present without checking live topsoil hydrogen, and checks live topsoil hydrogen only when event state is absent.
5. In `hourly_process_driver.zig`, replace the tautological test with tests that directly invoke `effectiveTopsoilHydrogen` on invalid event state, invalid live state, and valid event state with invalid live state.

## Proposed change
- `ecosys-audit/tests/starte_mloop_oracle.f`: emit per-cycle species values for P=0 for M=20..1000.
- `ecosys-ng/src/stages/hourly_process_driver.zig`:
  - `triggerDailySpeciation`: apply `ph = -log10(ahy_raw * 1e-3)` and `ahy1 = 10.0**(-(ph - 3.0))`.
  - Add helper `pub fn effectiveTopsoilHydrogen`.
  - Use `effectiveTopsoilHydrogen` in `executeHourlyScience` for both snow and direct atmospheric input, dropping the unconditional live hydrogen check.
  - Update unit tests to exercise `effectiveTopsoilHydrogen`.
- `ecosys-ng/src/soil/chemistry/snow_initialization.zig`:
  - Emit per-cycle values for M=20..1000.
  - Replace symmetric tolerances with `[min, max]` interval assertions over gfortran P∈{0,1,2} trajectories.

## Prediction
1. Zig matches gfortran P=0 to 1e-12 up to a specific cycle M, where a libm/rounding difference appears.
2. Zig M=1000 species values fall strictly inside `[min, max]` of the legacy P∈{0,1,2} M=980..1000 envelope.
3. Intra-day changes and invalid live hydrogen do not affect dynamic speciation when event state is active.
4. `effectiveTopsoilHydrogen` returns `error.InvalidTopsoilHydrogenForDynamicInput` when event hydrogen is invalid or when live hydrogen is invalid without event state.

## Falsification condition
1. First divergence >1e-12 is caused by a missing/incorrect term rather than floating-point libm/rounding.
2. Any species at M=1000 falls outside `[min, max]` of the gfortran P∈{0,1,2} envelope over M=980..1000.
3. `effectiveTopsoilHydrogen` fails to reject invalid inputs or incorrectly rejects valid event state.
