# HYPOTHESIS: T-00053

## Observed defect
The Ottawa simulation isolates `SoluteReactionSolverDidNotConverge` to the hourly dynamic-input equilibration path (`executeHourlyScience` -> `equilibratedDynamicInput` -> `equilibrateWithWorkspaceAndFailureReport`). As established in T-00050 and T-00051, this is not caused by the deck runtime iteration ceiling, but by a chemistry-equivalence mismatch between the legacy Fortran `reads.f` -> `starte.f` equilibration branch and the Zig hourly chemistry update sequence.

## Evidence
- `f77src/reads.f:712-749`: converts precipitation solute concentrations to molar units and stores them in landscape arrays (`CN4RI`, `CNORIG`, `CPORG`, etc.).
- `f77src/starte.f:128-141`: seeds initial K=1 ions (`PH1`, `CHY1`, `CN4Z`, etc.).
- `f77src/starte.f:241-242, 258-264, 324-329`: closed-form initial speciation for carbonate/bicarbonate, ammonium/ammonia, and phosphate species at initial `CHY1`.
- `f77src/starte.f:408, 439`: `DO 1000 M=1,MRXN` runs with `AHY1 = 10.0**(-(PH(L,NY,NX)-3.0))` held strictly constant across all 1000 iterations. Hydrogen is not an active unknown; pH is fixed and never solved for.
- `ecosys-ng/src/stages/hourly_process_driver.zig:81-141, 603-676`: `equilibratedDynamicInput` invokes `equilibrateWithWorkspaceAndFailureReport` on every wet hour with dynamic salts enabled.
- `ecosys-ng/src/soil/chemistry/snow_initialization.zig:532-675`: `equilibrateGenericWithWorkspaceAndFailureReport` initializes `carbonate = 0` and `bicarbonate = 0` (omitting legacy lines 241-242), and dispatches to the general Newton--Anderson reaction solver (`solveCellWithWorkspaceAndTrace`) which treats hydrogen as an active degree of freedom in an unbuffered cell with zero exchange and zero mineral capacity.

## Proposed mechanism
The chemistry-equivalence mismatch at the hourly input-equilibration boundary is localized in the reaction residual update logic:
1. In legacy `starte.f`, precipitation/irrigation equilibration is evaluated at fixed hydrogen activity (`AHY1 = 10.0**(-(PH-3.0))`), so all aqueous dissociation reactions (ammonium, carbonate, phosphate) are uncoupled linear relaxations that satisfy zero-residual equilibrium in a single cycle.
2. In Zig, when `carrierFreeAnalyticalEquilibrium` fails physical acceptance, the generic solver's reaction residual update logic treats hydrogen as an active degree of freedom in a zero-buffer aqueous cell. Newton--Anderson iteration steps produce severe residual oscillations on the unbuffered hydrogen row, exhausting the iteration budget.
3. State initialization also differs (Zig seeds zero carbonate/bicarbonate while legacy computes closed-form initial values), but state initialization alone does not cause solver non-convergence if hydrogen is fixed as in legacy.

## Proposed change
Add a bounded matched-state replay packet test in `ecosys-ng/src/soil/chemistry/snow_initialization.zig` that directly reconstructs the legacy `reads.f` -> `starte.f` precipitation state and compares:
1. Legacy state initialization (`reads.f` molar conversion + `starte.f` closed-form speciation) vs Zig state initialization (`snow_initialization.zig`).
2. Legacy fixed-pH reaction residual update logic (`starte.f:408-1227`) vs Zig coupled-hydrogen Newton--Anderson reaction residual update logic (`reaction_solver.solveCellWithWorkspaceAndTrace`).
3. Verify that the fixed-pH update converges to exact zero residuals matching legacy, whereas the unbuffered floating-hydrogen Newton--Anderson update is the cause of solver non-convergence/stagnation.

## Prediction
The bounded matched-state replay packet will show that:
1. State initialization difference (omission of initial carbonate/bicarbonate) perturbs the initial state, but does not prevent convergence if pH is held constant.
2. Reaction residual update logic with a floating hydrogen degree of freedom in an unbuffered cell exhibits severe Newton--Anderson residual oscillation and fails or struggles to converge, whereas legacy's fixed-pH residual update logic satisfies zero-flux equilibrium in 1 cycle.
3. This localizes the equivalence mismatch definitively to the reaction residual update logic (floating unbuffered hydrogen degree of freedom versus legacy fixed-pH equilibration).

## Falsification condition
If the generic Newton--Anderson solver with floating hydrogen converges to legacy equilibrium within 100 iterations regardless of buffering, or if legacy `starte.f` actually updates `AHY1`/`CHY1` during its `M=1,MRXN` loop, this hypothesis is falsified.
