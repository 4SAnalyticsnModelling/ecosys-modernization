# Control plane

Authority: `protocol.md`. Current target: `cycle.json`; verified progress: `frontier.json`;
priorities: `backlog.md`. Run `./scripts/project.sh pickup` for a read-only recovery packet.
Use `cycle_runner.py` for gates. Reports cite artifacts.
`state.md` is orientation only. `worker.json` configures the future autonomous worker;
`finish.json` is created only after F1–F7 evidence exists and `completion.py` validates it.

[Numerical recovery](playbooks/convergence-and-balance.md) is the shared procedure for near-zero
scaling, signed balance defects, negative pools, nonlinear stalls, NaN/Inf and unexplained
spikes; load it when those arise. Unrecoverable invalid states must fail before publication.
