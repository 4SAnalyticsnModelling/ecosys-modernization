T-00053 adds a test and changes no production code. Its main scientific claim holds, and I checked it myself against the source: in legacy STARTE, H+ is fixed and the carbon species are never updated inside the equilibration loop, while Zig treats H+ as free. The test itself should not be kept as written, because most of its assertions can never fail and it never runs the Newton–Anderson solver it blames.

DECISION: REVISE. Keep only the assertions that can tell legacy and Zig apart, and correct the legacy semantics the test assumes (below). Deciding whether to align Zig with fixed-pH input speciation is a separate SAGE decision task. It is out of scope for this review.

## EVIDENCE
Verified facts (read with f77query):
- `f77src/starte.f:129`: sets `CHY1=10**(-(PHR-3))` for K=1. The only other `CHY1=` assignments are `:151`, `:210` (before the loop) and `:1727` (after). None is inside `DO 1000 M` (`:408-1227`). So H+ is fixed.
- `f77src/starte.f:241-242`: the only `CCO31=`/`CHCO31=` assignments before the loop (plus `:1747-1748` after it). `RHCO3`/`RCO2Q` are computed at `:846-858` but never applied to the carbon states. The result says "ZERO flux accumulators"; that is imprecise. The fluxes exist and are simply not applied.
- `f77src/starte.f:439`: sets `AHY1=10**(-(PH(L,NY,NX)-3))`, which is the soil-layer pH, not `PHR`. The loop's dissociation quotients use `AHY1` (`:840,848,856,1039-1055`), while the initial speciation uses `CHY1` from `PHR`. The test's statement that "every reaction quotient equals the equilibrium constant at M=1" is therefore only true when `PH(L)=PHR`.
- `f77src/soil.f:106-108`: STARTE runs at start-up and when the day changes (`IDAYR.NE.IOLD`). It does not run hourly. Legacy has no hourly precipitation equilibration to match the Zig hourly call.
- `f77src/starte.f:1234-1253`: precipitation outputs (`CHYR=CHY1`, `CHCR=CHCO31`, …) are taken from the `I=1,L=1` pass.

Defects in the diff (`snow_initialization.zig`, added test):
- The legacy residuals are built from the same closed-form expressions and then checked to be zero. That is an identity: the checks cannot fail.
- `legacy_*_m_flux`, `zig_init_carbonate` and `zig_init_bicarbonate` are literal `0.0` values that the test then asserts are zero. No Zig code is exercised by these checks.
- `solveCellWithWorkspaceAndTrace` is never called, so "severe Newton–Anderson oscillation" is not tested.
- The only discriminating assertion is `carrierFreeAnalyticalEquilibrium` returning pH < 6 against legacy's 7.0.
- The comments contradict each other (pH "~5.65" vs "~5.73").
- `dissolved_co2_g_per_m3 / 12.0` assumes the input is in g C, which the test does not verify.
- `_ = ... / legacy_chy1` computes a value and throws it away.
