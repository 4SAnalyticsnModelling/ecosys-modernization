Authority: `.agent/protocol.md`. One model, autonomous decisions and recovery, no approval
queue. Finish F1–F7 for one integrated Zig 0.17.x candidate; preserve every scientific gate.
Choose the next unblocked task by prerequisite value and information gained per repeated work.

| Order | Deliverable | Exit evidence |
|---|---|---|
| 1 | Reconcile cycle 3, existing N patch, h4320 checkpoint and h4556 failure | Parent replay, exact signature, owned diff, ruled-out hypotheses |
| 2 | Mineral-N matched-state legacy oracle and minimal regression | Supply/consumption terms, floors, update order and units mapped to legacy lines |

| 4 | Reproducible complete legacy Ottawa baseline | Exact compiler/flags/deck hashes, final time and output inventory |
| 5 | Output dictionary and state-binding register | Every required field has producer, units, time support, conversion and comparison rule |
| 6 | Process/interface audit and DEV retirement | Bidirectional traceability, discriminating tests, no unexplained science gap |

| 8 | Profile and optimize the scientifically accepted model | Equivalent-work improvements; revalidate science after each change |
| 9 | Frozen qualification/release | All-column parity, restart equivalence, reproducibility, full-run ReleaseFast faster than optimized Fortran, F1–F7 certificate |

Use kernel/one-step → coupling → event replay → full suite → campaign. Never rerun the
30-year deck to answer a local question. Capture failed states as reusable fixtures. Cross-revision
replays are diagnostic; final evidence requires a strict single-binding trajectory from hour 0.
Background campaigns may coexist with cheap source/output audit, never duplicate full runs.

Before each experiment record hypothesis, falsifier, binding and simulated window. After it
record result and next action. Three unproductive experiments require a smaller reproducer or
new hypothesis. Preserve complete source scope; prioritize the Ottawa path without dropping
dormant branches. Prepare the complete legacy baseline and source/output audit during science waits. Runtime
optimization begins only after F1–F5 pass; earlier timing is limited to diagnosing a blocked
correctness run. Revalidate scientific acceptance before crediting an optimized candidate.

Current gaps are tasks, never assumed passes: preserved legacy baseline is partial; the output
provenance CSV and native adapters need completion. Keep the assessed tooling suite current;
historical Python failures are not active blockers after a current pass. Zig/host comparison
history does not prove oracle parity. Do not reinstall old workflows or toolchains.
All commands use `scripts/project.sh`; discover actual model/legacy CLI before registering argv.

Prerequisites are explicit: populate mineral-N bindings while resolving cycle 3; extend the
register by process. Baseline preparation and output/rule definitions are unblocked work during
long experiments. Before ENTRY, run `readiness.py --output-inventory <reviewed-inventory.json>`;
before CAMPAIGN, establish complete source/DEV dispositions and assessed required suites.
Freeze comparison rules before evaluation; retained replacement physics requires predeclared
envelopes and held-out independent benchmarks. Preserve failed and missing evidence as blockers.
Before RELEASE, validate structured F2–F6 reports and the schema-2 finish certificate.
See [qualification evidence](ecosys-audit/qualification-evidence.md) for exact interfaces.
Workflow-only maintenance records its own evidence; it does not advance cycle 3 or the frontier.

Progress and recovery: use the launcher's RESUME → REPLAN → WAITING_FOR_CHANGE contract.
An unchanged failed scientific experiment is prohibited even on the first restart. Record the
smallest distinguishing measurement and the changed hypothesis/input/source before retrying.
If three experiments produce no discrimination, shrink the failing state or audit a different
producer/consumer boundary; another full replay is not a new experiment. Workflow maintenance
must fix an observed execution blocker and then return to the science critical path. Do not
create cycles merely to restate a plan. Every external wait names an observable unblock condition,
a read-only probe and the next unblocked prerequisite. No unavailable credential can be inferred.

Live unattended runtime qualification is a deployment prerequisite, separate from scientific
ENTRY. Bootstrap it with isolated benign harness/service fixtures and preserved repo-local
backup/restore evidence; do not require F1–F7 or launch duplicate science to qualify the launcher.
Use `source_inventory.py` before source review; raw F2/F3 rechecks and the paired F6 benchmark
are mandatory at final acceptance. Defining rules/metrics and writing native adapters remain
scientific work; synthetic workflow fixtures establish no physical acceptance thresholds.
